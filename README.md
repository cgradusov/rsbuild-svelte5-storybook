# rsbuild-svelte5-storybook

Monorepo for [`storybook-svelte-rsbuild`](./packages/storybook-svelte-rsbuild) — a Storybook framework that runs **Svelte 5** components on top of **Rsbuild** / Rspack.

## Layout

- `packages/storybook-svelte-rsbuild` — the framework package (published to npm).
- `examples/basic` — a working Storybook with both `.stories.ts` and `.stories.svelte`.

## Develop

```sh
bun install
bun run build              # build the framework package
bun run storybook          # start the example on http://localhost:6006
bun run build-storybook    # produce static Storybook
```

## Release (npm + GitHub Releases)

This repo uses [Changesets](https://github.com/changesets/changesets) for versioning and a GitHub Actions workflow that publishes to npm and creates a GitHub Release automatically.

### One-time setup

1. Create an **Automation token** on npmjs.com and add it as `NPM_TOKEN` in
   GitHub → *Settings → Secrets and variables → Actions*.
2. Make sure the repo `package.json`'s `repository.url` points to your GitHub repo
   (replace `USER` in `packages/storybook-svelte-rsbuild/package.json`).

### Cutting a release

```sh
bun x changeset                  # describe the change (creates a markdown file in .changeset/)
git add . && git commit -m "feat: ..."
git push
```

The `Release` workflow opens a "Version Packages" PR. Merge it → npm publish + GitHub Release with autogenerated notes will run automatically.

### Manual release

```sh
bun x changeset version
bun run build
cd packages/storybook-svelte-rsbuild
npm publish --access public
cd ../..
git tag storybook-svelte-rsbuild@$(node -p "require('./packages/storybook-svelte-rsbuild/package.json').version")
git push --tags
gh release create "storybook-svelte-rsbuild@$(node -p "require('./packages/storybook-svelte-rsbuild/package.json').version")" --generate-notes
```

### Install from a GitHub Release (without npm)

Upload a tarball asset to the release once:

```sh
cd packages/storybook-svelte-rsbuild && npm pack
gh release upload storybook-svelte-rsbuild@0.1.0 storybook-svelte-rsbuild-0.1.0.tgz
```

Consumers can then install via:

```sh
bun add -d https://github.com/USER/rsbuild-svelte5-storybook/releases/download/storybook-svelte-rsbuild@0.1.0/storybook-svelte-rsbuild-0.1.0.tgz
```
